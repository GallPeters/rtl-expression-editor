about=The built-in QGIS editor does not always display mixed right-to-left and left-to-right text correctly, causing text to become difficult to read and edit. This plugin adds an improved text editor on top of the existing QGIS editor, providing proper RTL and LTR text support while preserving all QGIS features, including field and function tools, validation, previews, and syntax highlighting. The enhanced editor works seamlessly with QGIS and stays synchronized with the original editor.
