name=RTL Expression Editor
qgisMinimumVersion=4.0
qgisMaximumVersion=4.99
description=Correct right-to-left (Hebrew, Arabic) text in QGIS expression and filter editors, with smart autocomplete from your own lookup tables.
about=QGIS's built-in expression editor cannot display right-to-left text properly: when Hebrew or Arabic is mixed with English, letters overlap and the cursor jumps around.

    This plugin places an editor that handles mixed-direction text correctly on top of the original one and keeps the two in sync. All QGIS tools keep working as usual: field and function lists, validation, preview and syntax highlighting.

    It also replaces QGIS's autocomplete. Press Ctrl+Space (or just type) to get fields, values, functions, variables and operators. You can add your own lookup table, for example road types with their descriptions, so the suggested values come with readable labels.

    With a lookup table configured, a Read mode switch shows the descriptions instead of the stored codes. The expression itself is never changed.

    Settings can be exported to a file and shared with colleagues.

** v1.7 (23.11.2026):
  - Fixed: @map_scale and other map, atlas and layout variables were missing from the suggestions.
  - Fixed: typing Hebrew or Arabic, or a value with spaces, closed the suggestion list or left duplicate text after accepting.
  - Fixed: accepting @variables or $functions doubled the @ or $ sign.
  - Fixed: text values from a lookup table were inserted without quotes.
  - Fixed: suggestions sometimes came from the active layer instead of the layer being edited.
  - Fixed: after leaving Read mode, Undo could bring the descriptions back into the expression.
  - Fixed: Read mode now updates when QGIS inserts a field or function, and numbers inside function calls are no longer labelled.
  - Fixed: clicking OK in Settings while the lookup table was unreachable erased its configuration; an unreachable table is now retried automatically.
  - Fixed: the lookup file stayed locked after closing Settings or unloading the plugin.
  - Improved: the suggestion list includes the layer's fields, shows variable help, follows the Expression Builder's group names, hides deprecated functions and is no longer cut off.
  - Improved: no more log messages on every dialog.
